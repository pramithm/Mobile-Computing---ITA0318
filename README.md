\# 📱 Mobile Computing – ITA0318



\## 📖 About the Repository



This repository contains laboratory experiments, practical implementations, and assessments related to the \*\*Mobile Computing (ITA0318)\*\* course.



The purpose of this repository is to maintain all academic practical work in one place and provide easy access to experiment programs, source code, and related documentation.



\## 🎯 Objectives



\- Understand the fundamental concepts of Mobile Computing.

\- Learn mobile communication technologies and architectures.

\- Implement practical experiments related to mobile networks.

\- Understand wireless communication and mobile network protocols.

\- Develop practical knowledge through laboratory exercises.
